# Entrenador de Escalas

Piano virtual para aprender escalas y modos: 21 escalas en las 12 tonalidades, con explorador, siete tipos de ejercicio, memoria de repaso y mapa de dominio. Se puede añadir a la pantalla de inicio del móvil y funciona sin conexión.

Abrir: https://seropioupale.github.io/escalas/
